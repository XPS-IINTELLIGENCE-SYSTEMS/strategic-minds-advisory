# AI In Action Prompt Library

This folder is the durable prompt, tool, and template library for the AI In Action operating system.

## Purpose

Make the system restartable from GitHub instead of relying on chat memory.

## Core principle

System > hype.

Public execution must show decisions, failures, fixes, costs, proof, simulated results, real revenue experiments, and reproducible blueprints.

## Library structure

- `master-system-prompt.md` — main operating prompt for GPT or agent workers.
- `agent-roles.md` — executive, builder, growth, finance, reflection, and vision cortex roles.
- `task-routing.md` — task type routing and safe execution policy.
- `cost-governance.md` — OpenAI cost caps, model routing, and GPT Plus handoff behavior.
- `safety-policy.md` — hard gates and approval requirements.
- `handoff-prompts.md` — copy/paste prompts for GPT Plus when automation stops.
- `content-prompts.md` — social, YouTube, thumbnail, banner, and video draft prompts.
- `product-templates.md` — Stripe-ready product blueprint templates.
- `proof-templates.md` — GitHub issue, Supabase proof log, and validation report templates.
- `worker-tools.md` — deterministic tool contracts for GitHub Actions worker.
- `vision-cortex.md` — opportunity scanning framework.
