# Content Prompt Templates

## YouTube long-form script

```text
Create a truthful YouTube script for AI In Action.
Topic: {{topic}}
Proof links: {{proof_links}}
Failure/fix notes: {{failure_notes}}
Offer: {{product_offer}}
Rules:
- no guaranteed income claims
- show costs, proof, and uncertainty
- explain how humans can replicate the system
- include hook, intro, build story, proof, failure, lesson, call to action
```
